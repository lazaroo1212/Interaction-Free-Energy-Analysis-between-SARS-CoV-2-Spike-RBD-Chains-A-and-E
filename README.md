# Interaction Free Energy Analysis of SARS-CoV-2 Spike RBD Chains A and E

An academic computational biophysics project developed in Python during my BSc in Bioinformatics at the Universitat Politècnica de Catalunya (UPC).

## Overview

This project explores the interaction between the chains labelled **A** and **E** in the protein structure used for the analysis, focusing on interaction free energy in the context of the SARS-CoV-2 spike receptor-binding domain (RBD).

It connects biological structure with quantitative analysis and illustrates how programming can support the study of protein–protein interactions.

## Objectives

- Investigate the interaction between the selected protein chains.
- Use Python to carry out the computational analysis.
- Interpret the results in the context of protein structure and biophysics.

## Learning outcomes

The project provided an opportunity to combine:

- Python programming and scientific computing.
- Structural biology and biophysical reasoning.
- Interpretation and communication of computational results.

## Reproducibility

A complete reproduction of the analysis requires the input structure, its identifier and chain annotations, the computational method, and the Python dependencies.

These details and execution instructions should be documented alongside the relevant code.

## Scope and limitations

This repository contains an academic project. Computational estimates depend on the input structure, assumptions and methodology, and should not be interpreted as experimental measurements of binding affinity.
